## r/Windows11: "Software Showoff Sunday" weekly thread (the only place they allow self-promo; rule 6 removed the standalone post)

Comment, attach `cover-grid.jpg`:

**Deck: one hotkey switches the whole Windows 11 desktop (free, open source)**

I came from Omarchy on Linux, where one key flips the whole look. On Windows a theme change meant five tools and twenty minutes: wallpaper, accent, taskbar styler, Start styler, Explorer, icon pack, terminal scheme. So I built one picker that does all of it in one click.

Press Win+T, pick a theme, and these change together: wallpaper, accent colors, taskbar, Start menu, notification center, File Explorer, folder and app icons, fonts, and Windows Terminal colors. 7 themes in the free tier: Tokyo Night, Catppuccin Mocha, Gruvbox, Nord, Everforest, Catppuccin Latte (light) and Amber Lab.

- Also in the box: next wallpaper (Win+Shift+W), a quick finder (Win+Space), a Win+scroll desktop switcher
- Deck, a themed fork of the open-source Files app, with six looks that follow the theme
- Drawn folder, drive and file-type icons per theme; app icons in your accent color
- Nothing phones home; everything runs as your user

Install: unzip, run `install.ps1`, then install Windhawk (free) and its Taskbar, Start, Notification Center and Explorer styler mods. It needs AutoHotkey v2 (free) and Developer Mode for the Deck file manager, because the app isn't code-signed yet, so SmartScreen will warn you. The README has every step and the undo list; the installer backs up the registry keys it touches first.

Source (MIT): https://github.com/bdonoho-coder/deck
25-second demo: https://youtube.com/shorts/zG9c3DHyT6Q

There is also an optional paid pack of 9 sci-fi HUD themes on my Gumroad; the free tier is complete on its own and I'll leave the store link out of this post.

Feedback I need most: how the install goes on a machine that is not mine, and which theme you would want next.

Disclosure: my own project. Most of the code and the generated wallpapers were written with an AI coding assistant (Claude Code); I set the design, drew the direction, and tested every build on my own machines. This post was drafted with the same assistant.
