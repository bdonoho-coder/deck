# Gumroad listings (copy for the two products)

## 1. Deck (free tier) - price $0+ (pay what you want, minimum 0)

**Name:** Deck - one-hotkey themes for Windows 11

**Summary:** Press Win+T and the whole desktop changes: wallpaper, accent colors, taskbar, Start menu, notification center, File Explorer, folder and app icons, Terminal colors and window outlines. Comes with Deck, a themed fork of the open-source Files file manager.

**Description:**

Deck is an Omarchy-style theme system for Windows 11. One hotkey changes everything at once, and every part is drawn to match: folder icons, drive icons, app icons, Explorer art, fonts and wallpapers.

Free tier, 7 themes: Tokyo Night, Catppuccin Mocha, Gruvbox, Nord, Everforest, Catppuccin Latte (light) and Amber Lab.

What you get
- Theme picker (Win+T), next wallpaper (Win+Shift+W), quick finder (Win+Space), Win+wheel desktop switch
- Deck, a file manager built on Files, with six looks (HUD, minimal, dossier, tree, console, cyber) that follow the theme
- Drawn folder, drive, bin and file icons per theme; app icons from Simple Icons in your accent color
- HUD Face fonts (five OFL fonts), generated wallpapers, Windows Terminal color schemes
- Full source on GitHub, MIT

Needs: Windows 11 64-bit, AutoHotkey v2 (free), Windhawk (free) with five mods for the taskbar, Start menu, notification center, Explorer and icons, and Developer Mode for the Deck app. Setup is one script plus one admin registry merge; the README walks through it and through undo.

This download is a short guide with the link to the GitHub release (the zip is 98 MB). Paying is optional and goes to the next themes.

Not affiliated with the Files Community, Omarchy or the color theme projects; credits and licenses are in the download.

## 2. Deck HUD pack - price $9.99

**Name:** Deck HUD pack - 9 sci-fi HUD themes for Windows 11

**Summary:** Nine HUD themes for the Deck theme system: Red Alert, Orange Ops, Amber Control, Cyan Panel, Neon Grid, Neon Synth, Neon Pulse, Iron Deck and Acid Signal. Grid wallpapers, drawn HUD icons, Explorer art, readouts in the Deck file manager.

**Description:**

The HUD pack turns the free Deck theme system into a full sci-fi console. Each of the nine themes brings:
- Two HUD wallpapers (frame with reticle and readouts, and a minimal grid); Acid Signal adds a retro synthwave set
- Folder, drive, Recycle Bin and file-type icons drawn as HUD panels in the theme accent
- App icons in the accent color or in the apps' own colors (switch in the picker)
- File Explorer top-area art: dot grids, tick scales, code labels
- In the Deck file manager: scan-line readout, clock, drive meters, and the cyber look's frames, plates and places rail in the theme color

Install: run the free tier first, then `install-pack.ps1 -DeckFolder <your Deck folder>` from the pack. Download all nine theme zips, or just the ones you want; each one works on its own.

One purchase covers your own PCs. Original work; fonts (SIL OFL) and Simple Icons (CC0) keep their licenses.
